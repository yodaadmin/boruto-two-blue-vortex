# VORTEX Manga Reader — V2

هذه النسخة تعيد تصميم الواجهة الرئيسية وقارئ الفصول مع الحفاظ على بنية Supabase الحالية.

## الملفات
- `index.html` — الواجهة الرئيسية الجديدة.
- `app.js` — تحميل بيانات المانجا والفصول + أغلفة الفصول + سجل القراءة.
- `reader.html` — قارئ الفصول مع إعدادات قراءة متقدمة.
- `admin.html` — لوحة الإدارة الحالية، محفوظة للعمل مع قاعدة البيانات الحالية.
- `assets/` — ضع فيه شعارات Vortex وملفات الغلاف الموجودة لديك.

## الملفات المطلوبة داخل assets
يفضل وجود:
- `vortex-mark-white.png`
- `vortex-mark-cyan.png`
- `cover.png` أو أي صورة غلاف تضع رابطها في حقل `cover_url` بجدول `manga`.

## مهم حول أغلفة الفصول
لا يحتاج النظام إلى عمود جديد في قاعدة البيانات. بطاقة كل فصل تستخدم **أول صفحة من الفصل** كصورة معاينة تلقائيًا من جدول `pages`. إذا أضفت لاحقًا `cover_url` أو `thumbnail_url` للفصل، سيحاول الموقع استخدامها أولًا.

## القراءة المحفوظة
يتم حفظ التقدم والإعدادات في `localStorage` على جهاز القارئ، ومنها:
- آخر فصل تمت قراءته.
- الصفحة/النسبة المئوية.
- وضع القراءة العمودي أو صفحة واحدة.
- الخلفية الداكنة/الدافئة/الفاتحة.
- عرض الصفحة.
- المسافة بين الصفحات.
- السطوع.
- إخفاء شريط القراءة.

## قاعدة البيانات
تم الإبقاء على:
- `manga`
- `chapters`
- `pages`
- Storage bucket: `manga-pages`

كما تم الإبقاء على روابط Supabase الموجودة في المشروع الحالي.
