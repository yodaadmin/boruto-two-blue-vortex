# Boruto Two Blue Vortex — Publishable starter

هذه نسخة بداية قابلة للنشر. تعمل محليًا ببيانات localStorage، ويمكن ربطها لاحقًا بـ Supabase.

مهم: لا تنشر صفحات مانجا محمية بحقوق النشر إلا إذا كان لديك إذن/ترخيص بذلك.

للنشر من الهاتف:
1. أنشئ مستودعًا عامًا أو خاصًا على GitHub.
2. ارفع ملفات هذا المجلد.
3. اربط المستودع بـ Cloudflare Pages أو منصة استضافة ثابتة.
4. عند الحاجة إلى إدارة سحابية، أنشئ مشروع Supabase واربطه بالكود.
